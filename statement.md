# Project Statement

## Problem Statement

Students often keep assignment deadlines and task details in different notes or applications. This makes it easy to lose track of pending work and upcoming deadlines.

The Student Task Tracker provides a small command-line solution for storing student details, assigning tasks, tracking completion, and identifying overdue tasks.

## Scope

The project covers basic student and task management, local file storage, validation, and CSV report generation. It is designed as a command-line application and does not include a graphical or web interface.

## Target Users

The primary users are students who want a simple way to maintain assignment and deadline information.

## High-Level Features

- Add and list students
- Add tasks for existing students
- List pending and completed tasks
- Mark tasks as completed
- Identify overdue pending tasks
- Save data locally using CSV files
- Export a task report
